# pynetdicom DICOM benchmark package manifest

The standalone archive contains the hash-locked pynetdicom and pydicom requirements, DICOM UL parser extension and tests, AFLNet no-forkserver and network-endpoint patches, valid C-ECHO/C-STORE seeds, campaign/replay/smoke evidence, exact Docker image cleanup evidence, source checksums, version lock, and acceptance record. Dependencies are fetched from PyPI during image build and pip verifies the pinned hashes. Cross-protocol automation experience stays in the central `基准化经验库.md` and is not duplicated in this package.
