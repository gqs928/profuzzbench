# Package manifest

This protocol-specific delivery contains the pinned BoringSSL source snapshot and provenance, Docker build recipe, upstream TLS server fuzz target invocation, build log/lock, preflight and formal run evidence, final metrics, and seed/evolved corpus.

The automatic-benchmarking framework experience entry is maintained only in the central `基准化经验库.md`; it is intentionally not included in this protocol package. The Docker image is not embedded in the ZIP and is removed after ZIP validation.
