# Package manifest — Apache ZooKeeper Jute protocol

The standalone archive contains the official version-pinned target image recipe, AFLNet adapter and parser test, connection-aware Jute seeds, lifecycle/reset/replay/smoke scripts, source locks, build identity logs, campaign results, and acceptance report.

The archive intentionally does not include the central automation experience library. Cross-protocol lessons belong in the shared `基准化经验库.md`, where entries from all implementations are aggregated.
