# Apache HTTP/2 baseline

This profile targets Apache HTTP Server 2.4.71 `mod_http2`, using direct cleartext HTTP/2 (`h2c`) over a local TCP connection. Each testcase opens one connection; the starter corpus contains single-request and two-request streams. TLS, HTTP/1.1 Upgrade negotiation, proxy modules, and external services are outside the benchmark.

The official Apache guide documents significant `prefork` restrictions: it processes one request at a time per HTTP/2 connection. The selected single-process `prefork` target therefore exercises a bounded direct-h2c profile, not concurrent-stream throughput. Apache logs `AH10034` for the prefork protocol-negotiation path; the separately configured `H2Direct` path checks the HTTP/2 preface. Strict `h2`-library smoke tests before and after the campaign received HTTP/2 200 responses with the served-body marker, confirming the direct path.

The AFLNet snapshot does not include an HTTP/2 parser. `patches/aflnet-http2.patch` adds one for this profile: it keeps the connection preface and a valid initial SETTINGS frame together as the first region, splits later complete request frames using their 24-bit length field, and treats response frame type and flags as state feedback. HPACK header blocks remain opaque to the feedback parser; Apache parses them. A separately hash-locked lifecycle patch allows a 100 ms response-drain interval, removes AFLNet's busy wait after `-K`, and retries interrupted `waitpid` calls. Apache uses the standard AFL forkserver, which starts before the server, so each testcase gets a fresh AFL-instrumented `httpd -DFOREGROUND -X` child; `-K` sends SIGTERM and the forkserver reaps the child. No launcher or skipped instrumentation check is used.

The formal campaign ran for 1,801 seconds and recorded 5,924 executions, 115 paths, 36.74% stability, 9.81% bitmap, no unique crashes, and three AFLNet hang classifications. The low stability and bitmap are disclosed as limits; the system `libnghttp2` dependency is not AFL-instrumented, so the bitmap does not represent full Apache source coverage. All 115 queued inputs replayed with a started and live target, 243 HTTP/2 response frames total, and clean controlled shutdown. The three AFLNet hang samples did not begin with a valid HTTP/2 preface; each received an HTTP/1.1 400 response, produced no HTTP/2 response frames, left Apache alive, and exited cleanly after controlled SIGTERM. They are malformed-input/no-HTTP2-response classifications, not server-process hangs.

Run `./build.sh`, then `./run-benchmark.sh`. See the [Apache HTTP/2 guide](https://httpd.apache.org/docs/2.4/en/howto/http2.html) and [`H2Direct` directive](https://httpd.apache.org/docs/2.4/mod/mod_http2.html#hdirect). Shared automation-framework experience is recorded in the central experience library and is not duplicated in this protocol package.
