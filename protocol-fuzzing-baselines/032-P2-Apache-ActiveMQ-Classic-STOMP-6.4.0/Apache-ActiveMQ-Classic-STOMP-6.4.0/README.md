# Apache ActiveMQ Classic STOMP benchmark

This profile targets Apache ActiveMQ Classic 6.4.0, the current active release listed by the upstream download page. It exercises STOMP 1.2 over loopback TCP/61613 in an isolated Linux container. The AFLNet adapter segments requests at the STOMP NUL terminator and maps CONNECTED, MESSAGE, RECEIPT, and ERROR responses to stable state IDs. The profile is black-box protocol-state feedback; it does not claim Java source coverage.

The target archive is verified against Apache's published SHA-512 sidecar. The runtime is Eclipse Temurin JRE 21.0.13+9, verified against its published SHA-256. The build script compiles AFLNet on the host (GCC, GNU Make, Git, Python 3) and embeds the resulting binary into the image. A minimal Graphviz-compatible DOT writer preserves AFLNet's IPSM output without adding Graphviz's GUI development stack to the image.

From the profile directory, run `./build-aflnet.sh`, then `docker build -t profuzzbench-activemq-classic-stomp:6.4.0 .`. Start the broker in an isolated local network namespace with host loopback: `docker run -d --name activemq-stomp-640 --network host -v "$PWD/results:/results" profuzzbench-activemq-classic-stomp:6.4.0`. Run the protocol smoke from the host with `python3 protocol_smoke.py`. Then run `docker exec -d activemq-stomp-640 bash /opt/benchmark/fuzz.sh /results/stomp-30m 1800`; the formal timer starts after AFLNet finishes seed dry-run and writes `fuzzer_stats`. After it finishes, run `./replay.sh activemq-stomp-640 /results/stomp-30m`; the wrapper copies the replay helper into the target container and replays every queue item inside the same network namespace, then archive the outputs. Remove the exact container and image after the package and checksums are verified.
