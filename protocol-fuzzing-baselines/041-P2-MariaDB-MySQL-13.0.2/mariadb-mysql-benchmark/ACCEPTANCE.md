# MariaDB Server 13.0.2 MySQL Classic acceptance record

- Target: official Docker image `mariadb:13.0.2-ubi10`; resolved digest `mariadb@sha256:f3132612b44fb8dc3fc7fc939fd8b9d8d31de45acddea40692f7fa0a64e54ad6`. Runtime SQL reported `13.0.2-MariaDB`.
- Scope: MySQL Classic `COM_QUERY` requests through the loopback authentication-terminating proxy. The proxy performs a fresh upstream handshake for each testcase; authentication negotiation is checked by smoke tests and is outside the fuzzed request stream.
- Formal AFLNet run: **1,801 active seconds** (requested 1,800), exit status 0. It recorded 7,191 executions, 408 total response-state paths (400 discovered), 100% stability, 0 unique crashes, 0 unique hangs, and `cycles_done=0`.
- This is a black-box network response-state run. `bitmap_cvg=0%` is not source-code coverage because the official database image is not instrumented.
- Queue replay: 408/408 samples established a proxy connection and every sample received a non-empty response. The replay recorded 276,630 response bytes in 10,949 MySQL packets, 1,109 error packets, 3,188 EOF packets, 5,972 result-header packets, 18 socket errors during response collection, and 68 idle-read timeouts (350 ms per testcase). The replay counters do not assert a server crash: after replay, the MariaDB container was still running with zero restarts, and a fresh `SELECT 1` smoke test returned a clean 5-packet result with no SQL error.
- MariaDB logged aborted client sessions while processing truncated, malformed, or incomplete packets. Together with the non-empty responses, zero AFLNet crash/hang counts, zero container restarts, and the post-replay smoke test, these are classified as testcase-level connection closes / response-read timeouts, not confirmed server crashes or persistent hangs.
- The listener binds to loopback only. The official MariaDB image and target container were removed after the result and replay evidence were recorded; the profile retains the scripts, source lock, results, replay report, and this acceptance record.
