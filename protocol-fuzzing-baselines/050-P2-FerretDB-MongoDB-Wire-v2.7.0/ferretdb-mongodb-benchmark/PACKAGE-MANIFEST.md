# Package contents

This delivery contains the FerretDB v2.7.0 MongoDB Wire Protocol benchmark profile, pinned source/image metadata, AFLNet parser and state-only patch, build evidence, seven seeds, the complete 30-minute campaign results, replay logs, preflight evidence, post-campaign smoke results, and precise Docker image cleanup evidence.

The central framework experience library is maintained separately; this per-protocol package contains no individual experience entry. Docker images are not bundled.
