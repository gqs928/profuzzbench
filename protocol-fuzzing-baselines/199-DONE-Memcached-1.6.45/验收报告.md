# Memcached ASCII/TCP 协议基准化验收报告

**验收日期：** 2026-09-28  
**对象：** Memcached ASCII 协议，TCP/11211  
**方法：** ProFuzzBench/AFLNet 风格的容器化构建、种子回放、状态反馈模糊测试与覆盖率采集

## 一、结论摘要

协议适配、正常业务回归、种子业务状态到达、AFLNet 状态反馈、核心代码覆盖、十次重复回放以及受控异常样本回放均已取得通过证据。30 分钟模糊测试运行完成，未发现真实崩溃或挂起。

可重建性所需的构建身份已闭环：Dockerfile 中的 AFLNet 与 Memcached 固定 commit 和镜像内 `build-versions.txt` 一致；基础镜像 digest、Ubuntu 软件源快照及关键工具包版本均有记录。`memcached_version=memcached UNKNOWN` 是程序版本字符串，不影响用固定 commit 标识源代码版本。修订后的完整 `acceptance.sh` 未从头端到端重跑；各验收步骤已分别完成验证。

## 三、模糊测试与重复性数据

30 分钟 AFLNet 运行记录：

- 执行数：1,538
- 队列路径：106
- `variable_paths`：91
- 稳定性：92.61%
- bitmap 覆盖率：2.73%
- 正常 fuzz 运行中的 unique crashes / unique hangs：0 / 0
- 运行由时限结束（exit 124），这是预设时长到达后的预期结果。

十次业务种子回放均保持 `STORED, VALUE, END, DELETED, END` 状态序列和相同响应哈希。行覆盖率范围为 15.1%–15.3%，分支覆盖率范围为 9.2%–9.4%，覆盖率差异均为 0.2 个百分点。

受控异常回放属于独立的验收用故障注入测试，不计入上述正常 fuzz 的崩溃数。
