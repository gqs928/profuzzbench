# ZLMediaKit RTMP baseline profile

This profile benchmarks ZLMediaKit's RTMP v3 listener with AFLNet response-state feedback. The official GitHub Releases page has no published release; `git ls-remote` confirmed this immutable commit as the current `master` head on 2026-11-11, so the target uses the latest available upstream source snapshot `fb3265725f0880da1f52a3cc6e6eb04bbc327fa3` (`master@fb3265725f08`). All submodule revisions and source archive hashes are locked in `source-lock.json` and `source/COMPONENTS.txt`.

The default ZLMediaKit log path is resolved relative to the executable directory, not the process working directory. The image pre-creates its `/opt/zlmediakit/log` and adjacent runtime directories with write permission before running as a non-root UID. The target listener is TCP `127.0.0.1:1935`; a local bridge on `127.0.0.1:1936` completes the RTMP handshake and connect exchange dynamically before passing AFLNet's mutated application messages. The formal 30-minute run must be the only protocol benchmark in flight. Run `./build.sh` for a clean build, source checks, 60-second preflight, replay and native gcovr validation (with only the incompatible vendored Onvif/PugiXML coverage metadata omitted). After the 1800-second run passes, `./package.sh` creates `../deliverables/48-ZLMediaKit-RTMP-fb326572.zip` and its SHA-256 sidecar; `./stop-server-and-remove-image.sh` removes the exact completed benchmark image/container.

The per-protocol ZIP contains build and campaign evidence. Protocol-agnostic benchmark lessons are recorded only in the shared framework experience library, not duplicated in this archive.
