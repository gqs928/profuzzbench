# Package manifest

The standalone protocol ZIP contains the pinned OpenSSL and AFLNet source archives, target/toolchain locks, seed and validation, scripts, build logs, failed preflight note, 60-second preflight, formal 30-minute corpus and replay evidence, and cleanup record for OpenSSL QUIC 4.1.0. The formal run completed, but its 19.81% AFL feedback stability requires review; the ZIP is an evidence delivery, not a stable baseline pass. The aggregated experience library remains in the central deliverables directory and is not bundled into this ZIP.
