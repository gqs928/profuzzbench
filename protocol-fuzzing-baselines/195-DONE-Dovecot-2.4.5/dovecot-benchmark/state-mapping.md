# Dovecot IMAP 状态映射

## 目标范围

被测链路是明文 IMAP/TCP：`imap-login` 接收连接并解析认证前命令，认证成功后切换到 `imap` 进程处理邮箱命令。回放种子包含连接欢迎行、能力查询、认证、邮箱选择和读写命令；普通命令按 CRLF 分段，APPEND 的字面量正文视作命令的一部分。

## AFLNet 响应状态

适配器仅从响应行的稳定字段生成状态，丢弃客户端标签、动态计数、邮箱名和自由文本。

| 状态编号 | 响应类别 | 业务含义 |
| --- | --- | --- |
| 0 | 起始哨兵 | 状态序列的固定起点，不代表服务端响应 |
| 1–4 | 未标记 `OK`、`NO`、`BAD`、`BYE` | 欢迎、认证前提示、错误及断开 |
| 10–13 | 带标签 `OK`、`NO`、`BAD`、`BYE` | 命令完成、拒绝、语法错误及断开 |
| 20 | `+` 继续响应 | 服务端等待客户端继续提供认证/字面量数据 |
| 30 | 空行、缺失状态字段等异常响应 | 可观察的协议边界异常 |
| 100–60099 | 对稳定响应原子做 FNV-1a 映射 | `CAPABILITY`、`EXISTS`、`FETCH`、`LIST`、`SEARCH`、`STATUS` 等协议阶段 |

状态散列只用于引导状态探索，不替代服务端响应校验。`parser-test.c` 检查欢迎、带标签完成、未标记数字响应、继续响应以及字面量边界。`protocol-smoke.py` 另行确认正常 IMAP 客户端流程到达 Dovecot 实际邮箱处理代码。

## 核心处理代码

覆盖回放按源码文件过滤 `src/imap-login/`、`src/imap/` 和 `src/lib-imap/`，逐输入保留行/分支计数。报告同时列出命中函数；`imap-login-client.c` 的客户端输入解析、`imap-client.c` 的命令处理及 `cmd-fetch.c`、`cmd-search.c`、`cmd-append.c` 等命令实现是验收关注对象。
